# Türkiye Kedi Meclisi Kararname Üreticisi

**Resmi, ciddi, tartışmasız ve biraz tüylü bir devlet yazılımı.**

Bu depo, 2026 yılında kurulmuş hayali Türkiye Kedi Meclisi'nin resmi kararname üretim motorudur.  
Amacı basit: insan siyaseti çok gürültülü olduğu için kararları kedilere devretmek.

## Ne yapar?

- Rastgele ama **resmi görünen** kararname basar.
- Kararnumarası, tarih, imza ve damga ekler.
- Hiçbir yasal geçerliliği yoktur. Bu bir özelliktir, hata değil.
- Python 3 yeter. Ek paket istemez. Devlet bütçesi kısıtlı.

## Kurulum

```bash
git clone https://github.com/Tentivory/kedi-meclisi-kararname-ureticisi.git
cd kedi-meclisi-kararname-ureticisi
python3 kararname.py
```

İstersen kaç kararname üretileceğini söyle:

```bash
python3 kararname.py 5
```

## Örnek çıktı

```
TÜRKİYE KEDİ MECLİSİ
KARARNAME NO: 2026/42

Gerekçe: Uyuyan milletvekillerinin rüyası bozulmasın.
Oy: 14 miyav / 2 hırıltı / 1 kutu içinde kaybolma
DAMGA: [PENCE]
```
